# COS480 - Trabalho Final de Construção de Banco de Dados — Grupo 3

Repositório destinado ao desenvolvimento, instrumentação e análise experimental de um Sistema Gerenciador de Banco de Dados (SGBD) modular para a disciplina de **Construção de Banco de Dados**. O foco central do projeto reside na avaliação comparativa e combinatória de diferentes políticas de gerência de buffer, estruturas de índices e tamanhos de bloco sob um ambiente de armazenamento simulado.
